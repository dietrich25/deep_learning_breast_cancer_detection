# Breast cancer detection using deep learning - An ensemble approach

## Overview
The project explores the use of CNNs for breast cancer detection on mammographic medical images. Using the CBIS-DDSM and Mini-MIAS dataset I set up, train and evaluate various fine-tuning methods with the ResNet, DenseNet and Inception pre-trained models.

## Objectives
**Explore and preprocess datasets**
**Set up and train CNN models (Resnet, DenseNet, Inception)**
**Assess model performance separately**
**Design, assess and compare ensemble approach with previous results**

## Datasets
**CBIS-DDSM**: https://www.cancerimagingarchive.net/collection/cbis-ddsm/
**Mini-MIAS**: http://peipa.essex.ac.uk/info/mias.html
